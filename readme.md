# Dependency Extractor

## 1. Общее описание
Проект предназначен для извлечения **прямых зависимостей Python‑пакета** из файлов `pyproject.toml` или `setup.py` для указанной версии.  
Программа читает конфигурацию из файла `config.toml`, формирует путь к репозиторию и версии пакета, затем выводит список зависимостей на экран.  
Поддерживается работа как с локальными файлами, так и с удалёнными URL.

---

## 2. Описание функций и настроек

### Функции
- **`read_file(path_or_url: str, mode: str) -> bytes`**  
  Читает файл локально или по URL. Возвращает содержимое в виде байтов.  
  - `mode = "local"` — чтение с диска.  
  - `mode = "remote"` — загрузка по сети.

- **`extract_dependencies_from_pyproject(data: bytes) -> list[str]`**  
  Парсит `pyproject.toml`, извлекает список зависимостей из секции `[project]`.

- **`extract_dependencies_from_setup(data: bytes) -> list[str]`**  
  Простейший парсинг `setup.py`: ищет блок `install_requires` и извлекает зависимости.

- **`collect_dependencies(settings: dict) -> list[str]`**  
  Формирует путь к файлам для указанной версии, вызывает парсинг и возвращает список зависимостей.

- **`main()`**  
  Загружает конфигурацию, выводит параметры и зависимости.

---

### Настройки (`config.toml`)
```toml
[settings]
package_name = "my_package"          # имя пакета
repository_url = "D:/repo"           # путь к репозиторию или URL
repo_mode = "local"                  # режим: local или remote
version = "1.0.0"                    # версия пакета (имя папки)
filter_substring = "lib"             # фильтр по подстроке (опционально)
```

## 3. Команды для сборки проекта и запуска тестов

### Запуск приложения 
Проект не требует отдельной сборки, достаточно наличия Python 3.11+ и стандартных библиотек (tomllib, re, os, urllib).

### Запуск приложения 

```bash
python cli_1.py
```
